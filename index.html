Secret Santa 交換禮物

  1. 建議每人準備一份 NT$200 以上、與跑步或跑者相關的交換禮物。
  2. 禮物需包裝完成，外包裝不寫姓名。
  3. 建議外包一層塑膠袋防雨。
  4. 報到時把禮物交給教練，教練會貼上編號。
  5. 兩組全部返回後一起抽籤，抽到自己禮物的編號就放回重抽。

🎄 Christmas Dress Code

  • 鼓勵紅色、綠色、白色聖誕穿搭；可搭配聖誕帽、鹿角及節慶配件。
  • 配件需固定好，不影響跑步；避免拖地或遮擋視線的服裝；鞋子仍以跑鞋為主。
  • 聖誕歡樂組最佳造型：最有聖誕氣氛的造型，由教練選出前三名，拆完禮物後頒獎。
